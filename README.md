## 📸 Aperçu & Design

Le site est conçu avec une esthétique **moderne, lumineuse et épurée** inspirée des meilleurs portfolios d'ingénieurs web :
- **Charte graphique :** Fond clair épuré (`#f8fafc`), cartes blanches en relief avec ombres subtiles, typographie contrastée noir ardoise (`#0f172a`) et accents en bleu royal électrique (`#2563eb`).
- **Performance :** 0 dépendance lourde, 100 % HTML5, CSS3 et JavaScript Vanilla pour un temps de chargement ultra-rapide et un score de performance optimal.
